# Fabrica звёзд — MVP

Публичный read-only дашборд на GitHub Pages, русский язык, светлая тема, mobile-first, верхние вкладки. Источник истины — приватный Content OS. Экспорт только разрешённых полей: названия, категории, статусы, даты, площадки, связи, цели, краткая главная мысль; без черновиков, источников и внутренних заметок.

## Требования
- Обзор: текущая неделя понедельник–воскресенье, нормы площадок, графики активности; без списка идей и рекомендаций. Недели независимы.
- Контент: банк неопубликованных идей по категориям, выделение дефицита, история публикаций, фильтры. Без отдельных страниц и назначения дат.
- Аналитика: неделя, месяц, квартал, год, всё время, произвольный диапазон. Уникальные материалы по связанным опубликованным публикациям; активность по публикациям; сравнение с активными целями. Неизвестные даты исключать из датированных отчётов, приблизительные отмечать. Отсутствие данных не означает отсутствие активности.
- Длительные темы: раскрываемые серии, даты и площадки выпусков, фиксированный размер при наличии, иначе бессрочная/не задана.
- Дефицит: цель минус фактическая доля за последние 30 дней по умолчанию; сортировка категорий по дефициту, идеи по приоритету. При отсутствии выборки показывать недостаточность данных.
- Без backend, авторизации, редактирования, календарной сетки, AI, аналитики аудитории (отложено).

## План
1. Контракт и безопасный экспорт.
2. Статический адаптивный интерфейс и расчёты.
3. Четыре вкладки и фильтры.
4. Проверки расчётов и приватности.
5. GitHub Pages и автоматизация обновления.

Критерии приёмки: реальные данные, отсутствие двойного счёта кросспостов, корректные пустые состояния, мобильный интерфейс без горизонтального переполнения, никаких приватных черновиков в публичном артефакте. Бэклог — GitHub Issues. Технический выбор MVP: HTML/CSS/JS без зависимостей; даты в локальном календаре браузера.
